# 前端 Mock 功能与验收说明

更新日期：2026-10-22。运行方式：在 `frontend/` 执行 `npm ci`、`npm run dev:h5`，打开 http://127.0.0.1:10086/。

## 可操作范围

| 模块 | 当前本地行为 | 验证方式 |
| --- | --- | --- |
| 列表 | 搜索、类别/状态筛选、日均统计参与物品追溯、空间切换 | 输入名称/品牌/型号；点击类别或状态；点击日均卡片 |
| 手动建档 | 仅名称即可保存；金额和日期可空；可选照片、独立凭证 | 手动添加，填写或选择字段并保存，刷新检查 |
| H5 表单 | 日期使用浏览器日期输入，分类/空间/角色使用下拉选择 | 直接选日期和类别；日期也可用键盘输入 |
| 档案详情 | 查看图片、展开资料与事件详情、编辑档案 | 点击物品，编辑金额/日期，检查天数、日均与历史同步变化 |
| 支出 | 新增或更正支出、费用和历史联动 | 追加支出；在费用明细中点击费用更正；空金额有提示 |
| 处置 | 出售、淘汰、回收金额校验、处置信息更正 | 选择处置方式；勾选无回收时自动填写 0 元，再确认 |
| 删除恢复 | 删除后进入回收站；恢复保留身份、资料与生命周期 | 详情 → 更多管理 → 删除；空间 → 回收站 → 恢复 |
| 迁移 | 个人档案迁入可编辑家庭，保留历史与凭证 | 详情 → 更多管理 → 迁入家庭；确认后检查两个空间 |
| 分析/记录 | 类别与状态可下钻、操作记录可打开档案 | 点击分析状态或类别；点击记录条目 |
| 家庭 | 创建家庭、使用 DEMO-FAMILY 模拟首次加入、成员角色修改/移除 | 空间 → 创建家庭/加入家庭/家庭成员与权限 |
| 邀请 | 生成本机邀请码、复制、撤销、模拟其他成员确认加入 | 管理者家庭 → 邀请成员，见下文 |
| 截图导入 | 示例字段校对、未知金额、赠品、重复决定、逐项确认、保存 | AI 截图导入，核对后逐件确认，再保存 |
| 导入失败恢复 | 图片级成功/失败场景、单图重试、人工字段保留、部分保存反馈 | 对照原图 → 模拟识别结果 → 运行模拟识别 |
| 转手输 | 带入第一件尚未处理商品的字段和图片，手动保存后标记原条目已保存 | 导入页底部 → 转手输；保留信息并保存 |
| 再次导入 | 完成或跳过全部条目后可开始新一批 | 导入页 → 开始新一批导入 |
| 持久化 | 档案、家庭、邀请及未完成草稿存于当前浏览器/小程序 | 保存后刷新；关闭表单后重新打开 |

## 邀请的完整本地演示

1. 切换至自己为管理者的家庭；也可创建测试家庭。
2. 打开「邀请成员」，选择查看者或编辑者，点击「生成本地邀请码」。
3. 可复制本机 `LOCAL-...` 码，或撤销待处理邀请。
4. 输入模拟成员姓名，点击「模拟受邀者确认加入」。这会创建一个本地模拟成员；当前用户仍是管理者。
5. 关闭弹层，打开成员列表，查看新增成员、修改其角色或移除。
6. 在「加入家庭」输入本机 LOCAL 码，可预览对应家庭并进入已加入的家庭；不会重复加入或更改当前角色。
7. `DEMO-FAMILY` 用于体验当前用户首次加入示例家庭的确认流程，重复操作不会增加重复家庭。

此演示不依赖另一个微信用户或设备；LOCAL 码只能在生成它的本机数据中解析。不设置真实邀请有效期或管理员转交政策。

## 截图与失败重试的演示

- 固定商品示例用于验证交互，**没有读取截图文字或调用 AI**；用户选择的图片仅在本机保存。
- 「选截图」支持选择本地图片；在原图管理中运行模拟识别，使待处理图片进入完成或失败状态。
- 选择「部分识别失败」后运行：最后一张图失败，其余图成功；只有一张图时该图失败。
- 「重试此图」只更新该图的状态和尝试次数；人工改过的商品名称、金额、日期等不被重写。
- 示例商品按顺序关联到本批次来源图；这只是确定性的测试关联，不是真实商品来源推断。
- 来源未就绪的条目不能直接作为识别结果保存；可重试、跳过该条目，或转为手动录入。
- 保存逐件反馈成功或错误，已成功条目只指向已有档案，不重复创建。
- 选择同一件实物时跳过新建；另一件实物需要明确独立建档，然后确认保存。

## 已修复的交互问题

- 邀请面板此前只有角色说明，现可生成/撤销邀请码并模拟成员加入。
- 原识别模拟只有延时，现有图片状态、失败、重试及可继续操作的结果。
- 原「转手输」打开空表单，现带入商品字段，保存后同步原校对条目。
- 导入完成后增加新一批入口，避免页面处于无法继续操作的结束状态。
- H5 日期/分类/角色等使用桌面可操作的控件；日期输入事件已验证可以写入持久化档案。
- H5 按钮原生 loading 与 React 动态子节点发生 DOM 渲染冲突，改为 React 维护加载指示，避免保存/重试时破坏按钮与弹层。
- 勾选无回收自动填入 0 元，仍需用户确认保存。
- 没有可迁入家庭时增加明确提示；草稿存储失败时保留页面输入并提示。

## 当前边界

- 默认用户购入后持续在用，按日历天数计算；不提供闲置功能。
- 默认会有只读家庭。查看者的录入、编辑和恢复按钮不可用属于权限行为，可切回个人空间或管理者家庭操作。
- 登录、真实 AI、跨设备同步与邀请、服务端权限尚待后端实现。
- 回收站永久清空、自动过期、管理员转交、家庭迁出/解散仍按 PRD 待确认，不作为可用功能展示。
- H5 顶部微信胶囊是平台外观示意，不承担应用业务操作。
- 浏览器交互验证和双端编译不能替代微信开发者工具与 iOS/Android 真机验收。
