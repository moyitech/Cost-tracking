# 家庭成员设计候选

独立交互设计稿，不修改正式前端，不连接真实成员接口。
入口：`index.html`，本机预览 http://127.0.0.1:10091/ 。
`review.html?v=1..5&width=320` 可检查单版窄屏。

五版：简洁名册、深绿家庭卡、角色分组、成员卡片、我的家庭名片。
统一以截图的管理者本人作为预览身份，管理者置顶、标记“我”、昵称编辑按需展开、其他成员使用独立权限面板。没有转交管理者、退出或解散入口。
已实际预览全部五版 360px 效果和第 4 版 320px；逐版检查昵称空值报错、保存、权限面板，第 1–4 版验证演示角色切换。

选定正式实现时：
- 成员按管理者、编辑者、查看者排序；同角色内当前用户优先，余下使用稳定顺序。
- 需要在后端分页之前保证全局排序，不能只重排已加载的一页。
- 对编辑者／查看者隐藏他人的权限操作，仅允许修改本人昵称。
- 第 5 版当前用户不是管理者时，管理者仍置顶，本人身份卡放在其后。
- 沿用当前异步内容变化后重新测量 Sheet 的修复。
- 上线前完成真实前端预览、原生弹窗／键盘验收与 build:weapp。
