# 空间页 · 独立交互预览

从仓库根目录启动：

```sh
python3 -m http.server 10092 --bind 127.0.0.1 --directory design/spaces-preview
```

打开 <http://127.0.0.1:10092/>。桌面侧栏提供个人、管理者、编辑者、查看者场景，以及 320 / 390 / 430px、外观、大字号和重置工具。移动端工具排在手机画面外。

纯手机画面：<http://127.0.0.1:10092/?mode=screen>。也可使用查询参数 `scenario=personal|admin|editor|viewer`、`theme=light|dark`、`text=large`，便于定点验收与截图。

## 设计与行为

- 个人头像同步顶部账户入口、个人空间、空间选择器和家庭成员中的自己；家庭头像独立，仅管理者可编辑。
- 头像选择支持 JPG / PNG / WebP，最大 10 MB，本地解码后居中裁切到 512×512；保存才生效，关闭或取消不改变当前头像。图片不上传、不持久化。
- 创建、加入仅位于「全部空间」；子流程在同一个底部面板内前进和返回，不叠加弹窗。
- 创建包含家庭名称和本人昵称；加入使用明确标记的模拟邀请。操作成功后切到新的模拟家庭。再次接受相同演示邀请进入已加入的家庭，不重复创建。
- 家庭管理者可以打开邀请并选择编辑者或查看者，演示分享仅在本地反馈，不会生成真实邀请或发送消息。
- 成员列表按角色排序、同角色本人优先；只允许修改本人家庭昵称。成员权限编辑沿用正式成员页，不在本次独立样稿中重复实现。
- 回收站恢复会更新当前空间的物品、数量和记录；查看者没有恢复操作。
- 底栏支持查看简单的同空间物品、分析与记录，便于观察空间切换与恢复后的反馈。
- 全部状态在当前页面内存中，刷新恢复初始值。无第三方脚本、远程图片、接口请求或浏览器持久化。

## 验收

关键状态截图与浏览器验收结果保存在 `output/spaces-preview/`。验收覆盖页面和模拟交互，不替代微信原生头像选择、真实微信分享、扫码和跨账号加入；这些流程仍待微信开发者工具或真机验证。

项目交付构建：在 `frontend` 中运行 `npm run build:weapp`，并运行 `npm run check:wxss` 检查原生 WXSS 语法。独立样稿没有修改正式前端、接口或数据库。
